# 조재욱 포트폴리오

보안 연구 분야의 자기소개, GitHub 프로젝트, 연락처를 제공하는 정적 포트폴리오 웹사이트입니다.

## 주요 구성

- 소개: 자기소개와 외부 프로필 링크
- 프로젝트: GitHub 공개 저장소 정보를 불러와 카드로 표시
- 연락처: 전화 및 외부 프로필 링크
- 화면 효과: 배경 Canvas 애니메이션과 스크롤 등장 효과
- 모바일 화면: 작은 화면용 메뉴 버튼

## 사용 기술

HTML5, CSS3, JavaScript, Canvas 2D, GitHub REST API를 사용합니다. 별도의 빌드 도구나 패키지 설치는 필요하지 않습니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 구조와 소개·연락처 내용 |
| `style.css` | 색상, 배치, 반응형 스타일, 전환 효과 |
| `script.js` | 메뉴, 애니메이션, GitHub 저장소 조회 및 표시 |

## 실행 방법

1. 저장소에서 **Code → Download ZIP**을 선택합니다.
2. ZIP 파일을 압축 해제합니다.
3. 세 파일을 같은 폴더에 둔 상태에서 `index.html`을 브라우저로 엽니다.

GitHub 프로젝트 조회와 Google Fonts 로딩에는 인터넷 연결이 필요합니다. 브라우저 환경에서 직접 파일을 여는 방식이 제한되면, Python이 설치된 환경에서 해당 폴더의 터미널에 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000`에 접속합니다. 서버 종료는 터미널에서 `Ctrl+C`를 누릅니다.

## 프로젝트 표시 방식

`script.js`의 `GITHUB_ID`에 지정된 계정에서 최근 업데이트된 저장소를 최대 30개 조회합니다. 그중 포크 저장소를 제외하고 스타 수가 많은 순서, 스타 수가 같으면 최근 업데이트 순서로 정렬하여 최대 6개를 표시합니다.

현재 화면의 '최근 업데이트 순' 안내 문구와 실제 스타 우선 정렬 기준에는 차이가 있습니다.

## 저장소 목록이 나오지 않을 때

- 인터넷 연결을 확인하고 페이지를 새로고침합니다.
- GitHub API 요청 제한이나 일시적인 오류가 있을 수 있으므로 잠시 후 다시 확인합니다.
- 브라우저 개발자 도구의 Console 및 Network에서 오류를 확인합니다.

API 조회 실패 시 프로젝트 영역에 실패 안내가 표시됩니다.
